# 记忆导航离线跟踪实验报告（简版）

## 一句话总结

记忆导航 = 用**历史记忆轨迹**引导盲人：先录制一条参考（记忆）轨迹，离线分析验证"测试轨迹能否跟随记忆轨迹、并在每个关键点给出盲人可执行的**方向指令**"。

## 做了什么

- **自适应切段建锚点**：沿轨迹按"转弯 / 视觉突变 / 距离过长"自动设置关键锚点，每个锚点保存**原图、语义文字、视觉特征**，并用**视觉大模型**提取图像里的文字（路牌 / 店名 / 招牌）。
- **给出方向指令**：每个锚点 / 关键点输出盲人可执行指令，如 `向3点钟方向前进8米`（12点=直行，3点=右转90°，9点=左转90°）。
- **测试轨迹跟随匹配**：把测试轨迹逐点匹配回记忆轨迹，输出跟随指标，验证"有没有走对、偏了多少"。
- **可视化**：生成 3 份可直接打开的离线 HTML 页面。

## 实验表格

| 项目 | 结果 |
|---|---|
| 记忆轨迹长度 / 锚点数 | 311 m / 41 个 |
| 测试轨迹长度 / 锚点数 | 210 m / 47 个 |
| 跟随匹配 good 占比 | 27.7%（good 26 / 中 23 / 偏离 45） |
| 横向误差（中位数） | 7.5 m |
| 视觉相似度（测试↔记忆） | 0.55 |
| 锚点帧对齐重复数 | 0（图像与位置正确对应） |
| 闭环卡死问题 | 已修复，方向指令正确 |

## 指标来源与定义

| 指标 | 含义 / 来源 |
|---|---|
| **锚点数** | 自适应切段得到的关键点：满足「转弯 \|Δθ\|>30°」「视觉突变（前后帧 DINOv2 外观差异>阈值）」「间距>20m 长直路强制补点」任一即设锚点，首末点必为锚点 |
| **good / degraded / lost** | 每个测试点匹配回参考轨迹的质量等级：横向误差≤3m 为 good、≤8m 为 degraded、其余为 lost（基于 `RouteMatcher` 投影到参考最近段） |
| **good 占比** | 测试点中 `good` 点数 / 总测试点数 × 100% |
| **横向误差** | 测试点位置到参考轨迹最近段的垂直距离（米），衡量"偏了多远" |
| **朝向误差** | 测试点当前朝向与参考轨迹在该处朝向的夹角（度），衡量"方向对不对" |
| **视觉相似度** | 测试点帧与最近参考锚点帧的 DINOv2 特征余弦相似度（0–1），衡量"看到的环境是否一致" |
| **帧对齐重复数** | 多个锚点被对齐到同一张帧的数量（0 表示每个锚点图都对应不同、正确的位置） |
| **闭环卡死** | 参考轨迹含闭环绕路时，匹配会卡在同一个点导致方向错误；已通过自适应放大匹配前视窗口修复 |

## 暴露的问题 / 待改进

1. **图像文字识别不够准确**：视觉大模型对锚点原图的文字识别存在**漏检 / 错字 / 多余误识别**（如把无关笔画识别成文字、店名识别不完整），当前仅作展示信息，不能直接作为可靠的地名导航依据。
2. **参考轨迹存在闭环绕路**：记忆轨迹中含一圈闭环（同一区域重复走过），与直行的测试轨迹不一致，会导致匹配"卡死在同一位置、方向错误"。虽已通过自适应前视窗口规避，但**根本问题（参考轨迹不够干净）仍在**，更稳妥的做法是录制时避免绕圈、或预处理时自动剔除闭环。
3. **跟随精度受数据偏差限制**：测试轨迹中段与记忆轨迹存在明显偏移，导致 good 占比偏低（27.7%）、横向误差中位数 7.5 m，反映**两次行走并非完全重合**，需用同路径、相近视角的重合数据进一步验证精度。
4. **帧率/起点依赖标定**：帧与 GPS 的对齐依赖 GPS 日志中的帧号标定；若日志缺失 `image_path`，只能退化为按帧率估算，精度下降。
5. **视觉相似度对视角敏感**：两次行走相机头部朝向不同，会降低同地点的视觉相似度，影响"环境是否一致"的判断。

## 关键结论

1. **锚点图像与位置正确对应**：用 GPS 日志自带的帧号标定，锚点图不再错位。
2. **解决参考轨迹闭环导致的卡死**：记忆轨迹含一圈闭环绕路，测试直行无闭环，原会卡在同一个点导致方向错误；已通过自适应前视窗口修复，方向指令正确推进。
3. **图像文字提取有效**：用视觉大模型从锚点原图识别出如"医诊所""怡宝"等真实文字。
4. **数据真实差异已量化**：测试轨迹中段与记忆轨迹存在偏差（good 占 27.7%、横向误差中位数 7.5 m），属两次行走的真实差异，工具如实反映。
